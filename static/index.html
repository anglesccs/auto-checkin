⚡ 一键同步本机全部登录态（推荐）
  1. 点击下方按钮下载一键启动器（已内嵌本服务地址与同步授权，无需再输入 IP / 端口 / 密码）
  2. 把下载的 .bat 拷到装有 Trae / WorkBuddy / Qoder / CodeArts 客户端的电脑上，双击运行， 自动安装依赖、提取本机全部登录态并导入，含 TRAE 网页版之外的桌面客户端凭据（token + refreshToken 可长期自动续期）
  3. 新版 WorkBuddy 客户端的 token 是加密存储的，解密密钥只存在于本机运行中的客户端进程内存， 只能用这个工具导入，下方手动粘贴无法导入这类 token
首次运行需电脑已安装 Python 3.9+；启动器会自动完成其余准备
为什么网页不能代替这个工具：登录凭据保存在「客户端那台电脑」的本地文件里， WorkBuddy 的解密密钥更是在客户端进程内存里 —— 本服务跑在 NAS 容器中，浏览器沙箱也读不到本机文件，所以这一步只能在客户端电脑上执行。 下面的手动导入适用于：本页所在电脑就是客户端电脑、且愿意手动取字段的情况。
通过 TRAE 网页版登录态导入（推荐，Docker 内可用）
  1. 浏览器打开 https://work.trae.cn 并登录（手机号 / 扫码均可）
  2. 按 F12 打开开发者工具 → 切到 Network（网络） 标签
  3. 刷新页面，点击任意一个发往 trae.cn 的请求
  4. 在 Request Headers（请求标头） 中找到 Cookie:，右键复制整串值
  5. 粘贴到下面输入框，点击导入。导入后每日签到会自动换取新 token，Cookie 失效前无需维护
通过桌面客户端登录态导入（token + refreshToken 可长期自动续期）

推荐直接双击 NAS运维工具\同步登录信息到NAS\同步登录信息到NAS.bat 一键提取并导入 （在装有 Trae 客户端的电脑上运行）。手动导入则在客户端电脑上运行 NAS运维工具\同步登录信息到NAS\extract_credentials.py，把输出中的字段填到下面。

通过 WorkBuddy 客户端登录态导入
  1. 打开 WorkBuddy 客户端并登录
  2. 打开目录 %LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\
  3. 用记事本打开里面的 *.info 文件，全选复制内容粘贴到下面
  4. 注意：新版客户端的 *.info 里 token 是加密的（内容含 "$wbEncrypted"），粘贴导入会报错——这类只能用上方 一键同步工具导入；只有旧版客户端的明文 token 才能手动粘贴
  5. token 过期后（日志会提示），重新打开客户端再导入一次
国际版（WorkBuddy AI）同样适用： 凭据 domain 为 www.workbuddy.ai 时，签到与状态查询会自动改用国际版接口 https://www.workbuddy.ai（与国内版路径一致）。
通过 Qoder 客户端登录态导入（token 可自动续期，基本免维护）
  1. 在装有 Qoder 客户端的电脑上，运行 tools\extract_qoder_credentials.py（需 Python 3.8+， 自动解密本机登录态并生成机器指纹）
  2. 把输出的 JSON 全选复制，粘贴到下面输入框导入
  3. 中国版（qoder.com.cn）账户会一并导入机器指纹——签名接口需要它， 若日后提示「风控拦截 / 活动列表为空」，重新运行提取工具更新指纹
  4. token 失效且自动续期失败时（日志会提示），重新运行提取工具导入一次
通过 CodeArts Agent 客户端登录态导入（STS 凭据可自动续期）
  1. 在装有 CodeArts Agent 客户端的电脑上，运行 tools\extract_codearts_credentials.py（需 Python 3.8+， 自动解密本机登录态）
  2. 把输出的 JSON 全选复制，粘贴到下面输入框导入
  3. STS 凭据约 1 小时过期，refresh_token 可自动续期； 若续期失败（日志会提示），重新运行提取工具导入一次
