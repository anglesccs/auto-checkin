# NAS 运维工具（使用说明）

本文件夹收纳「本机 ↔ 飞牛 NAS」之间的两个运维动作，各自独立成文件夹，可以单独拷走。

| 文件夹 | 双击运行 | 作用 | 是否单 BAT |
|---|---|---|---|
| `部署代码到NAS/` | `部署代码到NAS.bat` | 把本机代码推上 NAS 并重建 docker 镜像 | ✅ 单 BAT（另带一份源码副本用于整包移植） |
| `同步登录信息到NAS/` | `同步登录信息到NAS.bat` | 把本机 Trae / WorkBuddy 登录态导入 NAS 服务 | ❌ 需搭配 2 个 .py（已放在同一文件夹） |

## 什么时候用哪个

| 场景 | 用哪个 |
|---|---|
| 改了 `checkin/`、`static/`、`Dockerfile` 等代码 | 部署代码到NAS |
| 控制台报 `HTTP 401：accessToken 已失效` | 同步登录信息到NAS |
| 「凭据有效期」列标红「已过期」 | 同步登录信息到NAS |
| 换了 NAS 机器 / 换了 SSH 账号密码 | 两个都要重新填一次（参数会被记住） |
| 控制台打不开、容器不见了 | 部署代码到NAS（顺带重建容器） |

## 放置位置

本文件夹应放在项目根目录下（与 `checkin/`、`Dockerfile` 同级），两个工具才能自动找到代码。
整包拷到项目外时的放置方法、`src_snapshot\` 用法，见本文件夹 `工具放置位置说明.txt`。

## 共同约定

1. **交互式问答**，直接回车 = 采用 `[]` 里的默认值。
2. 回答会记在同目录的 `deploy.conf` / `sync.conf` 里，下次免重复输入。
   **密码一律不落盘**，每次都要重新输。
3. 命令行也可以带参数预填（不弹交互也能跑），见各自的使用说明。
4. 提示语为中文（2026-09-28 起全部 bat 已中文化）。写法约定：文件存 UTF-8（无 BOM）+ 在 `@echo off`
   之后第一行加 `chcp 65001>nul`；标签名保持 ASCII。改 bat 时按这四条自查
   （GBK 存档 / 漏 chcp / chcp 排在中文之后 / 中文标签名都会坏），并用 `bat_lint.py` 复核。
5. 运行环境要求：Windows 10 1803 以上（自带 `ssh` / `scp` / `tar`）。

## 排错去哪查

| 想了解 | 看哪 |
|---|---|
| 接口口径、积分三种口径、`claimed` 规则、时区坑 | 项目根目录 `系统说明与部署.md` |
| 症状 → 结论对照表（报 400、状态灰、积分虚高、幽灵用户…） | 本机技能 `nas-auto-checkin-ops` |
| 直接探官方接口、判断 token 是否过期 | 项目根 `tools/diagnose_workbuddy.py` |
| 前端渲染回归 | 项目根 `tools/ui_check.js` |

## 已验证事实（2026-09-28 实测）

- 部署：本机 → `<SSH用户名>@192.168.x.x:/vol2/1000/docker/auto-checkin`，打包上传 + 重建，退出码 0，容器 `Up`。
- 同步：`2/2 个账户已导入远端服务`（Trae CN 余额 300、workbuddy-desktop 余额 383.32）。
- 三个 `.bat`（部署 / 同步 / install-deps）都过了 `windows-bat-launcher` 的 `bat_lint.py`
  （CRLF、UTF-8 无 BOM、chcp 65001 在前、标签 ASCII）并用测试副本真跑验证
  （2026-09-28 中文化版本）。
